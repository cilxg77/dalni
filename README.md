# دلّني — نسخة أولية

## التشغيل
1. ثبّت Python 3.10 أو أحدث.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:
   pip install -r requirements.txt
4. ثم:
   streamlit run app.py

سيفتح الموقع في المتصفح.

## الشعارات
مجلد `assets` جاهز. عند توفر ملفات الشعارات، ضعيها فيه ويمكن ربطها مباشرة في `app.py`.
حالياً توجد أماكن مؤقتة للشعارات حتى لا نحتاج الملفات الأصلية.

## المزايا الحالية
- الصفحة الرئيسية
- اختيار وجهة سياحية
- تحدي 30 ثانية
- شاشة نتيجة
- تصميم عربي RTL بطابع سياحي
- أماكن ثابتة للشعارات الثلاثة

## التطوير التالي المقترح
- تسجيل صوت المتسابق من المتصفح
- تقييم الكلام آلياً
- نقاط وترتيب للمتسابقين
- قاعدة بيانات
- لوحة تحكم للمشرف
